# Delta AI — Interactive Dashboard Sidebar

A polished, GitHub Pages-ready dashboard sidebar with responsive mobile drawer behavior, smooth dropdowns, glass/3D depth, and a user-provided looping video background.

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## GitHub Pages
Upload `index.html`, `styles.css`, and `background.mp4` to the repository root, then enable GitHub Pages from the repository settings.

## Notes
- `background.mp4` is the user-provided background video.
- No external libraries or CDNs are required.
- Reduced-motion settings are respected.
